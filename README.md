# Velnqora (VLNQ)

ERC20 token and NFT marketplace project, deployed on the Sepolia testnet.

## Token details
- Name: Velnqora
- Symbol: VLNQ
- Total supply: 1,000,000,000
- Standard: ERC20 (burnable)
- Solidity version: 0.8.27
- Network: Sepolia testnet

## Features
- Fixed supply minted to the deployer on creation
- Holders can burn their tokens
- Planned use inside an NFT marketplace

## How to deploy
1. Open the contract in Remix
2. Compile with Solidity 0.8.27
3. Deploy to Sepolia using MetaMask
4. Enter the recipient address as the constructor argument

## Status
Testnet only. Not audited.
